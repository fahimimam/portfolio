That makes the site host-locked to whatever baseURL was set at build time. Visiting the same build from a different domain (or from `hugo server` on localhost) silently redirects every click to the production domain. This override swaps those calls for relURL / relLangURL, so the rendered links are bare paths (`/projects/`, `/blog/`, …) and the browser appends them to whatever host is in the address bar.
