## TL;DR

I'm Fahim Imam, a backend-leaning software developer based in Bangladesh. I work
professionally on payment infrastructure and run a bunch of small self-hosted
side projects on a tiny VPS. Day-to-day, I write Go, deploy binaries, and try to
keep things boring in the best possible way.

## What I work with

**Languages:** Go, Python, JavaScript (just enough to glue things together).

**Backend:** Standard library plus [`chi`](https://github.com/go-chi/chi) or
[`fiber`](https://gofiber.io/) depending on the project. PostgreSQL when I need
real persistence, SQLite when I don't, Redis when I need speed.

**Infrastructure:** Linux, Nginx, Caddy. Bare-metal binaries over Docker for
anything on the VPS, because every megabyte of RAM matters on a 1-core, 2GB box.

**Tooling:** Git, tmux, neovim, `rsync` for deploys, a small notebook of bash
aliases.
